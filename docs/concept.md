# ストレスボールガチャ — 기획·컨셉 설계 (10월)

## 한 줄 컨셉
누르면 찌그러지고, 떼면 출렁이며 돌아오는 스트레스볼을 가챠로 모으는 앱.
실제 촉감 대신 **보고·움직여서 풀리는 경험**을 만든다.

## 핵심 원칙
1. **만지는 기분이 1순위** — 가챠·수집은 볼을 계속 만지게 하는 장치.
2. **일반 볼은 도형과 색, 레어 볼은 동물 캐릭터** — 이미지 에셋 없이 전부 코드(CustomPainter)로 그린다.
3. **한 손 / 짧은 세션** — 앱을 열고 10초 안에 볼을 만질 수 있어야 한다.

## 볼 디자인 체계
볼 = **형태 × 색(base, accent) × 무늬 × 레어도**

| 요소 | 종류 |
|---|---|
| 형태 (`BallShape`) | まる / しかく(squircle) / たまご / はな / なみ |
| 무늬 (`BallPattern`) | むじ / ドット / ストライプ / ツートン / キラキラ |
| 레어도 (`Rarity`) | N 60% · R 28% · SR 10% · SSR 2% |

레어도가 올라갈수록 형태·무늬가 특별해지도록 배치했다.

- **N (8종):** 기본 형태 + 단색/도트
- **R (6종):** 스트라이프·투톤, はな·なみ 형태 등장
- **SR (4종):** 동물 캐릭터 — しろねこ(생선), しばいぬ(뼈다귀), もちうさぎ(당근), こぐま(별)
- **SSR (2종):** 왕관 + 반짝이 캐릭터 — きんいろねこ(하트), よぞらペンギン

캐릭터는 말랑한 모찌 몸통에 귀·얼굴·손발·소품을 얹는 구조 (`lib/ui/widgets/character_art.dart`).

전체 목록은 `lib/data/ball_catalog.dart` (20종).

> 형태는 모두 극좌표 반지름 함수 r(θ)로 정의했다. 11월 변형 구현 때 누른 위치를
> 기준으로 r(θ)를 줄였다가 스프링으로 되돌리면, 모든 형태에 같은 로직을 쓸 수 있다.

## 화면 구성 (UI/UX)

```
[하단 탭]
 ├─ ガチャ (메인) ── Start / 핸들 → 결과 다이얼로그 (NEW! / 레어도 / 보유 수)
 │                                 └─ コレクションを見る → 컬렉션 탭
 ├─ コレクション ── 보유 볼만 3열 그리드 (없으면 「ガチャへ」 안내)
 │                 └─ 탭 → 상세 (크게 보기 · 눌러보기 · 형태/무늬 정보)
 └─ 図鑑 ────── 전체 20종을 레어도별(SSR→N)로, 배출률·섹션별 수집 수 표시
                   미보유는 흑백 + 「未入手」, 보유 볼 탭 → 상세
```

| 화면 | 역할 | 10월 상태 |
|---|---|---|
| ガチャ | 메인. 가챠 돌리기만 담당. 실물 캡슐토이 자판기 모양, Start(또는 핸들) → 핸들 회전 → 캡슐 낙하 → 결과 | 동작함 |
| 結果ダイアログ | 뽑은 볼 공개, NEW 표시 | 동작함 |
| コレクション | 내가 가진 볼 모아보기 | 동작함 |
| 図鑑 | 어떤 볼이 있는지 전체 종류 + 컴플리트율 | 동작함 |
| ボール詳細 | 볼을 눌러보는 메인 체험 | 누르면 축소→탄성 복귀 (임시) |

### 톤 & 컬러
파스텔, 둥근 모서리, 부드러운 그림자. 토큰은 `lib/ui/theme.dart`의 `AppColors`.

## 미결 사항 (11월 전에 결정)
- **과금(課金):** 실제 결제(IAP)인지, 게임 내 재화(코인)인지. 실제 결제면 스토어 설정·심사 일정이 추가된다.
- **가챠 제한:** 무제한 vs 하루 N회 / 코인 소모.
- **사운드:** 누를 때 효과음 유무, 진동(haptic) 사용 여부.
